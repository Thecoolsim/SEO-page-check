Vérification SEO d’une page

Remplissez les champs ou importez le code source HTML d’une page. Fonctionne pour les articles et les pages vidéo (YouTube ou Vimeo). Chaque vérification est notée bon, moyen ou mauvais, et se met à jour pendant la saisie. Les règles suivent les usages du référencement en français.

Importer depuis le code source d’une page
  1. Ouvrez la page dans votre navigateur.
  2. Affichez le code source : Ctrl+U sous Windows ou Linux, Cmd+Option+U sur Mac (dans Safari, activez d’abord le menu Développement).
  3. Sélectionnez tout, copiez, puis collez ci-dessous.
